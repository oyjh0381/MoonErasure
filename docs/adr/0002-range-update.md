# 字节区间校验更新

新增接口扩展当前领域，不改变已发布二进制格式。适用于磁盘页、备份块与文件记录小范围修改；不生成稀疏校验传输帧，不认证旧代。数据旧片段、校验须属于同一一致旧代，宿主将新数据和校验作为同代提交。

采用有界算法和独立 oracle 验证。O(p log p + mL + mD)，空间 O(mL+p)。p 为区间数，m 为校验片数，L 为整片长度，D 为变化字节总数。排序检查同片重叠后，GF 计算仅处理变化区间；完整校验片仍读取和复制。相比已有整片 update_parity，减少变化数据输入及其不变部分的计算。内部容器显式私有，公开方法继续可用；直接内部字段访问须迁移。源码扩展尚未发布。
